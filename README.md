# 商家退款分析 Demo

得物商家后台退款分析页面的交互演示，所有订单和金额均为程序生成的示例数据。

包含按退款时间／支付时间切换、今日及历史查询、三类退款核心数据和趋势切换、筛选吸顶、退款原因分析、商品与SKU分析、订单下钻和CSV导出。退款订单数按子订单去重，三类退款互斥且完整覆盖全部退款。所有分类和金额均为模拟数据，当前未接入生产接口。

## 本地预览

```bash
python3 -m http.server 8766
```

打开浏览器访问本地服务即可预览。

## 发布

GitHub Pages 从 `main` 分支根目录发布。更新 `index.html`、`styles.css`、`app.js` 后推送即可重新部署。
